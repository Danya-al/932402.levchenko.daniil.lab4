## Описание

Скрипт `script.js` работает с массивом калорийности блюд: считает статистику, фильтрует данные и выводит результат пользователю.

## Реализовано

**Ввод и вывод**

- `prompt` — запрос имени пользователя
- `alert` — приветствие и итоговая калорийность
- `console.log` — подробная статистика

**Функции**

- `findMax(numbers)` — поиск максимума через цикл `for` со счётчиком
- `filterHigh(numbers, limit)` — отбор блюд выше заданного порога
- `getSum(numbers)` — суммирование элементов массива

**Условия и циклы**

- `if / else` при проверке введённого имени
- Цикл `for...of` для подсчёта низкокалорийных блюд (≤ 300 ккал) и их доли
- Дополнительное условие: при сумме выше 3000 ккал в консоль выводится рекомендация распределить рацион на два дня

## Данные

Массив из 7 значений калорийности. Порог высококалорийных блюд — 600 ккал, низкокалорийных — 300 ккал.
